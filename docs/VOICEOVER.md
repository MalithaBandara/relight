# Voice-over script

For the AI narration service the owner uses. One block per shot, in order. Paste each block as its own clip (or the whole
file with the pauses kept) so the clips can be placed on the timeline exactly. Pace: about 2.5 words per second; the
"max words" figure is what fits the slot at that pace, so ask the service for a calm, even pace and trim if a clip runs long.

Pronunciation: Relight (ree-LITE), Muse Spark, SAM 3.1 ("sam three point one"), Voice Transcribe, SCADA ("skay-da"),
Sinhala (SIN-ha-la), Galle (gawl), Wakwella (wak-WEL-la). Spell out "github dot com slash MalithaBandara slash relight"
if the service reads URLs badly.

Say on the recording or in the submission text that the narration is AI-generated.
